# Diagnosis: create an agent with MCP tools using DeepWiki server

## Root Cause Analysis

**Phase with Issue**: Code Phase

**What went wrong**:  
The explore phase successfully found relevant files including `camel/toolkits/mcp_toolkit.py` and `camel/agents/chat_agent.py`, which contain the correct usage pattern for MCP tools with DeepWiki. It also found example MCP agent files. Thus, the explore phase provided sufficient and correct information.

However, the code phase failed to follow the correct usage pattern. Instead of using `MCPToolkit.create()` to instantiate the toolkit and then retrieving tools via `get_tools()` to pass to a `ChatAgent`, the generated code directly passed a local configuration dictionary with an invalid `"type": "custom"` to `MCPAgent`. This caused a validation error and connection timeout.

Specifically:  
- The generated code used `MCPAgent` with a `local_config` dict instead of using `MCPToolkit` and `ChatAgent` with tools.  
- The `"type"` field in the server config was set to `"custom"`, which is invalid; valid types are `'sse'`, `'websocket'`, `'stdio'`, or `'streamable_http'`.  
- The agent initialization pattern did not match the ground truth or the documented usage in the codebase.  
- The timeout was not increased from the default 10s, which is recommended for DeepWiki.

## Suggested CAMEL.md Improvements

### New Rule to Add

- When creating an agent with MCP tools, always use `MCPToolkit.create()` with the server config dict and then retrieve tools via `get_tools()`. Pass these tools to a `ChatAgent` instance rather than passing the config dict directly to `MCPAgent`.
- Validate the server config `type` field to be one of the accepted values: `'sse'`, `'websocket'`, `'stdio'`, or `'streamable_http'`. Do not use `"custom"` as a type.
- For DeepWiki MCP server usage, set an explicit timeout (e.g., 60 seconds) to avoid connection timeouts.
- Use `ChatAgent` with MCP tools for tool-enabled agent interactions, not `MCPAgent` with local config.

### Example Pattern to Add

```python
import asyncio
from camel.models import ModelFactory
from camel.types import ModelType
from camel.agents import ChatAgent
from camel.toolkits.mcp_toolkit import MCPToolkit

DEEPWIKI_CONFIG = {
    "mcpServers": {
        "deepwiki": {
            "url": "https://mcp.deepwiki.com/mcp",
            "timeout": 60.0
        }
    }
}

async def main():
    mcp_toolkit = await MCPToolkit.create(config_dict=DEEPWIKI_CONFIG, timeout=60.0)
    deepwiki_tools = mcp_toolkit.get_tools()

    model = ModelFactory.create(model_type=ModelType.GPT_4O)
    agent = ChatAgent(model=model, tools=deepwiki_tools)

    query = "Use DeepWiki's tools to retrieve the architecture of the camel-ai/oasis GitHub repository."
    response = await agent.astep(query)
    print("=== DeepWiki MCP Agent Response ===")
    for msg in response.msgs:
        print(msg.content)

    await mcp_toolkit.disconnect()

if __name__ == "__main__":
    asyncio.run(main())
```

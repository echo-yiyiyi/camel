## Suggested CAMEL.md Improvements

### New Rule to Add

- When a task explicitly requires a specific tool (e.g., "tools to search duckduckgo"), the code agent must use the exact tool attribute or method (e.g., `SearchToolkit().search_duckduckgo`) rather than a generic method returning multiple tools (e.g., `get_tools()`).

### Example Pattern to Add

```python
from camel.agents import ChatAgent
from camel.models import ModelFactory
from camel.toolkits import SearchToolkit
from camel.types import ModelType

# Instantiate Gemini model
model = ModelFactory.create(
    model_type=ModelType.GEMINI_2_5_PRO,
    model_config_dict={"temperature": 0.0}
)

# Get DuckDuckGo search tool specifically
search_tool = SearchToolkit().search_duckduckgo

# Create agent with the specific DuckDuckGo tool
agent = ChatAgent(model=model, tools=[search_tool])

response = agent.step("Search CAMEL-AI framework on DuckDuckGo and provide summary.")
print(response.msgs[0].content)
```

### Search Technique to Add

- Add targeted grep or symbol search for specific toolkit attributes or methods named after the required tool, e.g., `search_duckduckgo`, to ensure the explore phase surfaces the exact tool usage pattern.
- Emphasize in exploration to identify not only the toolkit class but also the specific tool attributes/methods that correspond to the requested tool.

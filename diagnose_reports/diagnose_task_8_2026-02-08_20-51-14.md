## Root Cause Analysis

**Phase with Issue**: Code Phase

**What went wrong**:  
The explore phase successfully found relevant files including the ArxivToolkit and vector retriever/storage implementations, and even example scripts related to RAG and Arxiv. The explore phase output shows the agent had access to the correct toolkit and vector retrieval classes.

However, the generated code failed to follow the explicit task requirement to download the paper PDF using `arxiv_toolkit.download_papers`. Instead, it only performed a search via the Arxiv tools and extracted text from the search results, which is not the same as downloading the actual PDF. The code agent also did not use the `VectorRetriever` class with explicit embedding and vector storage as shown in the ground truth. Instead, it used `VectorDBMemory` and stored the search result text as a memory record, which is a different approach and does not satisfy the task's intent.

## Suggested CAMEL.md Improvements

### New Rule to Add

- When a task requires downloading papers or documents, explicitly instruct to use the toolkit's download method (e.g., `download_papers`) rather than only searching or extracting metadata.
- For RAG tasks involving academic papers, emphasize building vector stores from the actual downloaded PDF content, not from search result text.
- Distinguish between searching metadata and downloading full content in toolkit usage instructions.

### Example Pattern to Add

```python
# Example pattern for downloading papers and building vector store from PDF

from pathlib import Path
from camel.toolkits.arxiv_toolkit import ArxivToolkit
from camel.embeddings import OpenAIEmbedding
from camel.retrievers.vector_retriever import VectorRetriever
from camel.storages import QdrantStorage

DOWNLOAD_DIR = Path("arxiv_papers")
DOWNLOAD_DIR.mkdir(parents=True, exist_ok=True)

arxiv_toolkit = ArxivToolkit()
arxiv_toolkit.download_papers(
    query="Attention Is All You Need",
    max_results=1,
    output_dir=str(DOWNLOAD_DIR),
)

pdf_files = sorted(DOWNLOAD_DIR.glob("*.pdf"))
pdf_path = pdf_files[0]

embedding_model = OpenAIEmbedding()
vector_storage = QdrantStorage(vector_dim=embedding_model.get_output_dim())
vector_retriever = VectorRetriever(embedding_model=embedding_model, storage=vector_storage)
vector_retriever.process(content=str(pdf_path), should_chunk=True)
```

### Search Technique to Add

- When searching for toolkit usage related to academic paper tasks, include search terms like `download_papers`, `pdf`, `VectorRetriever`, and `process` to find examples that download and vectorize PDFs.
- Search for example scripts or notebooks that demonstrate RAG over downloaded PDFs, not just search results.

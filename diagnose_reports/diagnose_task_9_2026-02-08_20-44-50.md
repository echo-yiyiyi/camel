## Suggested CAMEL.md Improvements

### New Rule to Add

- When a task explicitly requires "human interaction tools," the code agent must use `HumanToolkit` or equivalent human interaction toolkits, not memory management toolkits like `MemoryToolkit`.
- The example query must demonstrate triggering the human interaction tools (e.g., prompting for user input), not just memory commands.
- When using `LongtermAgentMemory`, ensure all required blocks (e.g., `vector_db_block`) are properly initialized and assigned to avoid runtime errors.

### Example Pattern to Add

```python
from camel.agents.chat_agent import ChatAgent
from camel.memories import LongtermAgentMemory, ScoreBasedContextCreator
from camel.toolkits.human_toolkit import HumanToolkit
from camel.models import ModelFactory
from camel.types import ModelType

def main():
    model_backend = ModelFactory.create(model_type=ModelType.DEFAULT)
    context_creator = ScoreBasedContextCreator(
        model_backend.token_counter,
        model_backend.token_limit,
    )
    longterm_memory = LongtermAgentMemory(context_creator=context_creator)

    human_toolkit = HumanToolkit()
    tools = human_toolkit.get_tools()

    agent = ChatAgent(
        system_message="You are a helpful assistant. Use tools to interact when needed.",
        model=model_backend,
        memory=longterm_memory,
        tools=tools,
        message_window_size=5,
    )

    input_query = "What can you do for me?"
    response = agent.step(input_query)
    print(f"Agent Response: {response.msgs[-1].content}")

if __name__ == "__main__":
    main()
```

- Search for example queries that trigger human interaction tools by looking for calls to `agent.step()` with queries like `"What can you do for me?"` or other prompts that invoke human input.

# Diagnosis: create an agent using the Gemini model with a tools to search duckduckgo

## Root Cause Analysis

**Phase with Issue**: Code Phase

**What went wrong**:  
The explore phase successfully found relevant files and identified the correct usage pattern for the DuckDuckGo search tool (`SearchToolkit().search_duckduckgo`). The code phase, however, generated code that used `SearchToolkit().get_tools()` which returns all search tools, not specifically the DuckDuckGo tool as required by the task. This is a subtle but important difference because the task explicitly requires using the DuckDuckGo search tool only. Using `get_tools()` is broader and does not satisfy the task requirement. The code agent failed to apply the specific usage pattern for the DuckDuckGo tool found during exploration.

## Suggested CAMEL.md Improvements

### New Rule to Add

- When a task requires a specific tool (e.g., "tools to search duckduckgo"), the code agent must use the exact tool attribute or method (e.g., `SearchToolkit().search_duckduckgo`) rather than a generic method returning multiple tools (e.g., `get_tools()`).

### Example Pattern to Add

```python
from camel.agents import ChatAgent
from camel.models import ModelFactory
from camel.toolkits import SearchToolkit
from camel.types import ModelType
from camel.configs import GeminiConfig

# Instantiate Gemini model
model = ModelFactory.create(
    model_type=ModelType.GEMINI_2_5_PRO,
    model_config_dict={"temperature": 0.0}
)

# Get DuckDuckGo search tool specifically
search_tool = SearchToolkit().search_duckduckgo

# Create agent with only DuckDuckGo tool
agent = ChatAgent(model=model, tools=[search_tool])

# Ask a question
response = agent.step("Search CAMEL-AI framework on DuckDuckGo and provide summary.")
print(response.msgs[0].content)
```

### Search Technique to Add

- When searching for usage of a specific tool, search for the exact attribute or method name (e.g., `search_duckduckgo`) in the toolkit files to find precise usage examples.
- Avoid relying solely on generic methods like `get_tools()` when the task specifies a particular tool.

---

This improvement will help the code agent generate code that strictly adheres to task requirements about tool usage, avoiding overgeneralization that leads to incorrect tool selection.

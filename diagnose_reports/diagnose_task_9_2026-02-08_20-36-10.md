## Suggested CAMEL.md Improvements

### New Rule to Add

- When a task requires an agent with human interaction tools, explicitly prefer and prioritize `HumanToolkit` over other toolkits like `MemoryToolkit`.
- The example query must demonstrate triggering the human interaction tool (e.g., a prompt for user input), not just memory management commands.

### Example Pattern to Add

```python
from camel.agents.chat_agent import ChatAgent
from camel.memories import LongtermAgentMemory, ScoreBasedContextCreator
from camel.toolkits.human_toolkit import HumanToolkit
from camel.models import ModelFactory
from camel.types import ModelType

def main():
    model = ModelFactory.create(model_type=ModelType.DEFAULT)
    context_creator = ScoreBasedContextCreator(model.token_counter, model.token_limit)
    longterm_memory = LongtermAgentMemory(context_creator=context_creator)
    human_toolkit = HumanToolkit()
    tools = human_toolkit.get_tools()
    agent = ChatAgent(
        system_message="You are a helpful assistant. Use tools to interact when needed.",
        model=model,
        memory=longterm_memory,
        tools=tools,
        message_window_size=5,
    )
    input_query = "What can you do for me?"
    response = agent.step(input_query)
    print(f"Agent Response: {response.msgs[-1].content}")

if __name__ == "__main__":
    main()
```

### Search Technique to Add

- When searching for human interaction tools, explicitly search for `HumanToolkit` and its usage examples by grepping for `HumanToolkit` or `human_toolkit` in toolkits and examples directories.
- Also search for example queries that trigger human interaction tools, e.g., queries containing "What can you do for me?" or similar prompts.

---

These improvements will help the code agent correctly identify and use the human interaction toolkit and write example queries that test human interaction, fulfilling the task requirements.

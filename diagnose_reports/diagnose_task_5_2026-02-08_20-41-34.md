# Diagnosis: create an agent with MCP tools using DeepWiki server

## Root Cause Analysis

**Phase with Issue**: Code Phase

**What went wrong**:  
The explore phase successfully found relevant files including `camel/toolkits/mcp_toolkit.py` and `camel/agents/mcp_agent.py`, indicating that the necessary information about MCP tools and agents was available. However, the code generation phase failed to correctly use the MCP tools as required by the task. Instead of creating an `MCPToolkit` instance and retrieving tools via `get_tools()`, the generated code directly passed a configuration dictionary with an invalid `"type": "custom"` to `MCPAgent`'s `local_config` parameter. This caused a validation error and connection failure. Moreover, the generated code used `MCPAgent` directly rather than a `ChatAgent` with MCP tools, which is the expected pattern for using MCP tools in Camel. The ground truth uses `MCPToolkit.create()`, sets a proper timeout, retrieves tools, and passes them to a `ChatAgent`. The generated code ignored this pattern, leading to runtime errors and failure.

## Suggested CAMEL.md Improvements

### New Rule to Add

- When creating an agent with MCP tools, always instantiate `MCPToolkit` using `MCPToolkit.create()` with the proper config dictionary and timeout, then retrieve tools via `get_tools()`. Pass these tools to a `ChatAgent` rather than using `MCPAgent` directly with a config dict.

- Validate MCP server config types against allowed values (`'sse'`, `'websocket'`, `'stdio'`, `'streamable_http'`) and avoid using unsupported types like `'custom'`.

### Example Pattern to Add

```python
import asyncio
from camel.models import ModelFactory
from camel.types import ModelType
from camel.agents import ChatAgent
from camel.toolkits.mcp_toolkit import MCPToolkit

DEEPWIKI_CONFIG = {
    "mcpServers": {
        "deepwiki": {
            "url": "https://mcp.deepwiki.com/mcp",
            "timeout": 60.0
        }
    }
}

async def main():
    mcp_toolkit = await MCPToolkit.create(config_dict=DEEPWIKI_CONFIG, timeout=60.0)
    deepwiki_tools = mcp_toolkit.get_tools()

    model = ModelFactory.create(model_type=ModelType.GPT_4O)
    agent = ChatAgent(model=model, tools=deepwiki_tools)

    query = "Use DeepWiki's tools to retrieve the architecture of the camel-ai/oasis GitHub repository."
    response = await agent.astep(query)
    print("=== DeepWiki MCP Agent Response ===")
    for msg in response.msgs:
        print(msg.content)

    await mcp_toolkit.disconnect()

if __name__ == "__main__":
    asyncio.run(main())
```

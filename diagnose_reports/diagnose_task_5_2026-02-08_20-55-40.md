# Diagnosis: create an agent with MCP tools using DeepWiki server

## Root Cause Analysis

**Phase with Issue**: Code Phase

**What went wrong**:  
The explore phase successfully found relevant files, including `camel/toolkits/mcp_toolkit.py` and `camel/agents/mcp_agent.py`, which contain the correct usage patterns for MCP tools and agents. However, the code generation phase failed to follow the correct usage pattern. Instead of using `MCPToolkit.create()` to instantiate the toolkit and then retrieving tools via `get_tools()` to pass to a `ChatAgent`, the generated code directly passed a configuration dictionary to `MCPAgent` as `local_config`. This caused:

- Use of an incorrect agent type (`MCPAgent` instead of `ChatAgent`).
- Bypassing the MCPToolkit abstraction and tools initialization.
- Using an invalid server type `"custom"` in the config, which is not accepted by the MCP client.
- Missing the explicit timeout setting (though this was acceptable).
- Resulting in runtime errors and connection failures.

- The generated code uses `MCPAgent` with a config dict, not using MCPToolkit or tools.
- The agent type and toolkit usage are incorrect.

## Suggested CAMEL.md Improvements

### New Rule to Add

- When creating an agent with MCP tools, always instantiate the MCPToolkit via `MCPToolkit.create(config_dict, timeout)`, then retrieve tools with `get_tools()`, and pass these tools to a `ChatAgent`. Do not pass the config dict directly to `MCPAgent` as `local_config`.
- Use `ChatAgent` (not `MCPAgent`) when working with MCP tools obtained from `MCPToolkit`.
- The server config for MCPToolkit must use valid server types (`'sse'`, `'websocket'`, `'stdio'`, `'streamable_http'`), not `'custom'`.
- For DeepWiki MCP server, use the official URL `"https://mcp.deepwiki.com/mcp"` and set timeout to 60 seconds to avoid connection timeouts.

### Example Pattern to Add

```python
import asyncio
from camel.models import ModelFactory
from camel.types import ModelType
from camel.agents import ChatAgent
from camel.toolkits.mcp_toolkit import MCPToolkit

DEEPWIKI_CONFIG = {
    "mcpServers": {
        "deepwiki": {
            "url": "https://mcp.deepwiki.com/mcp",
            "timeout": 60.0
        }
    }
}

async def main():
    mcp_toolkit = await MCPToolkit.create(config_dict=DEEPWIKI_CONFIG, timeout=60.0)
    deepwiki_tools = mcp_toolkit.get_tools()

    model = ModelFactory.create(model_type=ModelType.GPT_4O)
    agent = ChatAgent(model=model, tools=deepwiki_tools)

    query = "Use DeepWiki's tools to retrieve the architecture of the camel-ai/oasis GitHub repository."
    response = await agent.astep(query)
    print("=== DeepWiki MCP Agent Response ===")
    for msg in response.msgs:
        print(msg.content)

    await mcp_toolkit.disconnect()

if __name__ == "__main__":
    asyncio.run(main())
```

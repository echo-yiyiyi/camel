## Suggested CAMEL.md Improvements

### New Rule to Add

- When a task requires "human interaction tools," explicitly require the use of `HumanToolkit` rather than `MemoryToolkit`.
- Example queries must demonstrate triggering human interaction tools (e.g., prompting user input), not just memory management commands.
- For longterm memory agents, ensure the `LongtermAgentMemory` is fully and correctly initialized, including setting `vector_db_block` and its storage to avoid runtime errors.

### Example Pattern to Add

```python
from camel.agents.chat_agent import ChatAgent
from camel.memories import LongtermAgentMemory, ScoreBasedContextCreator
from camel.toolkits.human_toolkit import HumanToolkit
from camel.models import ModelFactory
from camel.types import ModelType

def main():
    model_backend = ModelFactory.create(model_type=ModelType.DEFAULT)
    context_creator = ScoreBasedContextCreator(
        model_backend.token_counter,
        model_backend.token_limit,
    )
    longterm_memory = LongtermAgentMemory(context_creator=context_creator)
    human_toolkit = HumanToolkit()
    tools = human_toolkit.get_tools()
    agent = ChatAgent(
        system_message="You are a helpful assistant. Use tools to interact when needed.",
        model=model_backend,
        memory=longterm_memory,
        tools=tools,
        message_window_size=5,
    )
    input_query = "What can you do for me?"
    response = agent.step(input_query)
    print(f"Agent Response: {response.msgs[-1].content}")

if __name__ == "__main__":
    main()
```

### Search Technique to Add

- Add explicit search for `HumanToolkit` usage examples when the task mentions "human interaction tools."
- Search for example queries that trigger human interaction tools, e.g., queries that prompt user input or use `HumanToolkit` tools.
- When searching for longterm memory examples, verify that `LongtermAgentMemory` is fully initialized with all required blocks (e.g., `vector_db_block`) and storage to avoid runtime errors.

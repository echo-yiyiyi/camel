# Diagnosis: 9_longterm_memory_single_agent

## Root Cause Analysis

**Phase with Issue**: Code Phase

**What went wrong**:  
The explore phase successfully found relevant files about longterm memory and toolkits, including the `HumanToolkit` and `MemoryToolkit`. However, the code generation phase incorrectly used `MemoryToolkit` instead of the required `HumanToolkit` for human interaction tools. This led to the agent having memory management tools rather than tools that enable human interaction (e.g., prompting the user). Additionally, the example queries tested memory save/load/clear commands rather than triggering human interaction tools as required by the task. The generated code also missed setting up the human interaction tools properly and did not use the example query that triggers human interaction.

## Suggested CAMEL.md Improvements

### New Rule to Add

- When a task requires "human interaction tools," explicitly prefer and prioritize `HumanToolkit` over other toolkits like `MemoryToolkit`.
- Example queries must demonstrate triggering the human interaction tools (e.g., prompting the user), not just memory management commands.

### Example Pattern to Add

```python
from camel.agents.chat_agent import ChatAgent
from camel.memories import LongtermAgentMemory, ScoreBasedContextCreator
from camel.toolkits.human_toolkit import HumanToolkit
from camel.models import ModelFactory
from camel.types import ModelType

def main():
    model_backend = ModelFactory.create(model_type=ModelType.DEFAULT)
    context_creator = ScoreBasedContextCreator(
        model_backend.token_counter,
        model_backend.token_limit,
    )
    longterm_memory = LongtermAgentMemory(context_creator=context_creator)
    human_toolkit = HumanToolkit()
    tools = human_toolkit.get_tools()
    agent = ChatAgent(
        system_message="You are a helpful assistant. Use tools to interact when needed.",
        model=model_backend,
        memory=longterm_memory,
        tools=tools,
        message_window_size=5,
    )
    input_query = "What can you do for me?"
    response = agent.step(input_query)
    print(f"Agent Response: {response.msgs[-1].content}")

if __name__ == "__main__":
    main()
```

### Search Technique to Add

- When searching for human interaction tools, explicitly search for `HumanToolkit` and its usage examples.
- Use grep or import search for `human_toolkit` or `HumanToolkit` to find relevant example scripts.
- Also search for example queries that trigger human interaction, e.g., `"What can you do for me?"` or similar prompts.

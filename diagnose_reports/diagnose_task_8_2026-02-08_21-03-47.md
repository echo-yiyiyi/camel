## Suggested CAMEL.md Improvements

### New Rule to Add

- When a task requires downloading papers with ArxivToolkit, explicitly use the `download_papers` method to obtain PDFs, not just `search_papers`.
- For RAG tasks involving academic papers, vector retrieval must be performed on the actual PDF content, not on search result metadata or abstracts.
- Use `OpenAIEmbedding` and `VectorRetriever` with `QdrantStorage` (or equivalent) to build vector stores from downloaded PDFs before querying.

### Example Pattern to Add

```python
from pathlib import Path
from camel.toolkits.arxiv_toolkit import ArxivToolkit
from camel.embeddings import OpenAIEmbedding
from camel.retrievers.vector_retriever import VectorRetriever
from camel.storages import QdrantStorage

# Download paper PDF
arxiv_toolkit = ArxivToolkit()
download_dir = Path("arxiv_papers")
download_dir.mkdir(exist_ok=True)
arxiv_toolkit.download_papers(query="Attention Is All You Need", max_results=1, output_dir=str(download_dir))

# Build vector store from PDF
embedding_model = OpenAIEmbedding()
vector_storage = QdrantStorage(vector_dim=embedding_model.get_output_dim())
vector_retriever = VectorRetriever(embedding_model=embedding_model, storage=vector_storage)
pdf_path = next(download_dir.glob("*.pdf"))
vector_retriever.process(content=str(pdf_path), should_chunk=True)

# Query vector store
question = "What is a Transformer?"
retrieved_chunks = vector_retriever.query(question, top_k=3)
context = "\n".join([chunk.get("text", "") for chunk in retrieved_chunks])
```

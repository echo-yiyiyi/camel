# Diagnosis: create an agent using the Gemini model with a tools to search duckduckgo

## Root Cause Analysis

**Phase with Issue**: Code Phase

**What went wrong**:  
The explore phase successfully found relevant files and identified the correct usage of the DuckDuckGo search tool (`SearchToolkit().search_duckduckgo`). The code phase, however, generated code that used `SearchToolkit().get_tools()` which returns all search tools, not specifically the DuckDuckGo tool as required by the task. This is a subtle but important difference because the task explicitly requires using the DuckDuckGo search tool only. The generated code thus did not strictly follow the task requirement and used a broader set of tools. This indicates the code agent did not correctly apply the information discovered during exploration about the specific DuckDuckGo tool usage.

## Suggested CAMEL.md Improvements

### New Rule to Add

- When a task explicitly requires a specific tool (e.g., DuckDuckGo search tool), the code agent must use that exact tool attribute or method (e.g., `SearchToolkit().search_duckduckgo`) rather than a generic or all-encompassing method (e.g., `get_tools()`).

### Example Pattern to Add

```python
from camel.agents import ChatAgent
from camel.models import ModelFactory
from camel.toolkits import SearchToolkit
from camel.types import ModelType
from camel.configs import GeminiConfig

# Instantiate Gemini model
model = ModelFactory.create(
    model_type=ModelType.GEMINI_2_5_PRO,
    model_config_dict={"temperature": 0.0}
)

# Use the specific DuckDuckGo search tool
search_tool = SearchToolkit().search_duckduckgo

# Create agent with the specific tool
agent = ChatAgent(model=model, tools=[search_tool])

# Ask a question
response = agent.step("Search CAMEL-AI framework on DuckDuckGo and provide summary.")
print(response.msgs[0].content)
```

### Search Technique to Add

- When the task mentions a specific tool by name (e.g., "DuckDuckGo"), explicitly search for method definitions or attributes named exactly after that tool (e.g., `def search_duckduckgo` or `search_duckduckgo` attribute) in the toolkits directory to find precise usage examples.
- Prioritize reading example scripts that demonstrate the exact tool usage rather than generic toolkit usage.

---

This improvement will help the code agent to correctly identify and use the exact tool required by the task, avoiding the mistake of using a generic or all-tools method that does not meet the task's specificity.

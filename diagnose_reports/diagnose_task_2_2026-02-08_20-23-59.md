# Diagnosis: create an agent using the Gemini model with a tools to search duckduckgo

## Root Cause Analysis

**Phase with Issue**: Code Phase

**What went wrong**:  
The explore phase successfully found relevant files and identified the correct usage of the DuckDuckGo search tool (`SearchToolkit().search_duckduckgo`). The code phase, however, generated code that used `SearchToolkit().get_tools()` instead of the specific `search_duckduckgo` tool. This caused the agent to be initialized with all search tools rather than only the DuckDuckGo tool, violating the task requirement. The generated code did not follow the exact API usage pattern for the DuckDuckGo tool as demonstrated in the ground truth and example files.

## Suggested CAMEL.md Improvements

### New Rule to Add

- When a task requires a specific tool (e.g., DuckDuckGo search tool), the code agent must use the exact attribute or method that returns that tool (e.g., `SearchToolkit().search_duckduckgo`), not a generic method returning multiple tools (e.g., `get_tools()`).

### Example Pattern to Add

```python
from camel.agents import ChatAgent
from camel.models import ModelFactory
from camel.toolkits import SearchToolkit
from camel.types import ModelType
from camel.configs import GeminiConfig

model = ModelFactory.create(
    model_type=ModelType.GEMINI_2_5_PRO,
    model_config_dict={"temperature": 0.0}
)

# Use the specific DuckDuckGo search tool, not all tools
search_tool = SearchToolkit().search_duckduckgo

agent = ChatAgent(model=model, tools=[search_tool])

response = agent.step("Search CAMEL-AI framework on DuckDuckGo and provide summary.")
print(response.msgs[0].content)
```

### Search Technique to Add

- Add targeted grep searches for specific tool attributes or methods when the task mentions a particular tool by name, e.g., search for `search_duckduckgo` in `toolkits/` to find the exact API usage.
- Prioritize reading example scripts that demonstrate the exact tool usage (e.g., `examples/vision/duckduckgo_video_object_recognition.py`) to extract precise usage patterns.

---

This will help the code agent to correctly identify and use the exact tool required by the task, avoiding generic or overly broad API calls that do not meet task constraints.

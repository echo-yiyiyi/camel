## Suggested CAMEL.md Improvements

### New Rule to Add

- When a task explicitly requires a specific tool (e.g., "tools to search duckduckgo"), the code agent must use the exact tool attribute or method (e.g., `SearchToolkit().search_duckduckgo`) rather than a generic or aggregate method (e.g., `get_tools()`).

### Example Pattern to Add

```python
from camel.agents import ChatAgent
from camel.models import ModelFactory
from camel.toolkits import SearchToolkit
from camel.types import ModelType

# Instantiate Gemini model
model = ModelFactory.create(
    model_type=ModelType.GEMINI_2_5_PRO,
    model_config_dict={"temperature": 0.0}
)

# Use the specific DuckDuckGo search tool, not all tools
duckduckgo_tool = SearchToolkit().search_duckduckgo

# Create agent with only the DuckDuckGo tool
agent = ChatAgent(model=model, tools=[duckduckgo_tool])

response = agent.step("Search CAMEL-AI framework on DuckDuckGo and provide summary.")
print(response.msgs[0].content)
```

### Search Technique to Add

- When the task mentions a specific tool by name, perform targeted grep searches for the exact tool attribute or method (e.g., `search_duckduckgo`) in the toolkits directory to find precise usage examples.
- Avoid relying solely on generic methods like `get_tools()` when the task requires a specific tool.

---

These improvements will help the code agent generate code that strictly adheres to task requirements about tool usage, avoiding substituting specific tools with generic collections of tools.

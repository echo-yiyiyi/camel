**What went wrong**:

## Suggested CAMEL.md Improvements

### New Rule to Add

- When a task requires "human interaction tools," explicitly prefer `HumanToolkit` over other toolkits like `MemoryToolkit`.
- Example queries must demonstrate triggering human interaction tools (e.g., prompting user input), not just memory management commands.
- For longterm memory agents, ensure proper initialization of all required memory blocks (e.g., vector_db_block, chat_history_block) to avoid runtime errors.

### Example Pattern to Add

```python
from camel.agents.chat_agent import ChatAgent
from camel.memories import LongtermAgentMemory, ScoreBasedContextCreator
from camel.toolkits.human_toolkit import HumanToolkit
from camel.models import ModelFactory
from camel.types import ModelType

def main():
    model_backend = ModelFactory.create(model_type=ModelType.DEFAULT)
    context_creator = ScoreBasedContextCreator(model_backend.token_counter, model_backend.token_limit)
    longterm_memory = LongtermAgentMemory(context_creator=context_creator)

    human_toolkit = HumanToolkit()
    tools = human_toolkit.get_tools()

    agent = ChatAgent(
        system_message="You are a helpful assistant. Use tools to interact when needed.",
        model=model_backend,
        memory=longterm_memory,
        tools=tools,
        message_window_size=5,
    )

    input_query = "What can you do for me?"  # triggers human interaction tool
    response = agent.step(input_query)
    print(f"Agent Response: {response.msgs[-1].content}")

if __name__ == "__main__":
    main()
```

### Search Technique to Add

- When searching for human interaction tools, explicitly search for `human_toolkit.py` or `HumanToolkit` class usage.
- Search for example queries or tests that demonstrate human interaction tool usage (e.g., prompts for user input).
- Also verify memory initialization patterns to ensure all required blocks are properly set up.

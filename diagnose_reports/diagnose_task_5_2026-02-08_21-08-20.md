# Diagnosis: create an agent with MCP tools using DeepWiki server

## Root Cause Analysis

**Phase with Issue**: Code Phase

**What went wrong**:  
The explore phase successfully found relevant files including `camel/toolkits/mcp_toolkit.py` and `camel/agents/chat_agent.py`, which contain the correct usage pattern for MCP tools and agents. However, the code phase generated code that bypassed the proper MCPToolkit usage and instead instantiated `MCPAgent` directly with a raw config dictionary (`local_config`) containing an invalid `"type": "custom"` field. This caused a validation error and connection failure.

Specifically:  
- The generated code did not use `MCPToolkit.create()` to instantiate the toolkit and get tools.  
- It did not use `ChatAgent` with tools, but used `MCPAgent` with a config dict.  
- The config dict used `"type": "custom"`, which is invalid per the server config schema (valid types are `'sse'`, `'websocket'`, `'stdio'`, `'streamable_http'`).  
- The ground truth explicitly sets the server URL to `"https://mcp.deepwiki.com/mcp"` and sets a timeout of 60 seconds, while the generated code used the URL from the task but no timeout and an invalid type.  
- The agent type and toolkit usage pattern were incorrect, leading to runtime errors.

## Suggested CAMEL.md Improvements

### New Rule to Add

- When creating an agent with MCP tools, always instantiate the MCPToolkit using `MCPToolkit.create()` with the appropriate config dict and timeout, then obtain tools via `get_tools()`. Pass these tools to a `ChatAgent` instance rather than passing raw config dicts to `MCPAgent`.

- Validate MCP server config types strictly; allowed types are `'sse'`, `'websocket'`, `'stdio'`, `'streamable_http'`. Do not use `"custom"` as a type.

- For DeepWiki MCP server usage, prefer the official URL `"https://mcp.deepwiki.com/mcp"` and set a timeout of at least 60 seconds to avoid connection timeouts.

### Example Pattern to Add

```python
import asyncio
from camel.models import ModelFactory
from camel.types import ModelType
from camel.agents import ChatAgent
from camel.toolkits.mcp_toolkit import MCPToolkit

DEEPWIKI_CONFIG = {
    "mcpServers": {
        "deepwiki": {
            "url": "https://mcp.deepwiki.com/mcp",
            "timeout": 60.0
        }
    }
}

async def main():
    mcp_toolkit = await MCPToolkit.create(config_dict=DEEPWIKI_CONFIG, timeout=60.0)
    deepwiki_tools = mcp_toolkit.get_tools()

    model = ModelFactory.create(model_type=ModelType.GPT_4O)
    agent = ChatAgent(model=model, tools=deepwiki_tools)

    query = "Use DeepWiki's tools to retrieve the architecture of the camel-ai/oasis GitHub repository."
    response = await agent.astep(query)
    print("=== DeepWiki MCP Agent Response ===")
    for msg in response.msgs:
        print(msg.content)

    await mcp_toolkit.disconnect()

if __name__ == "__main__":
    asyncio.run(main())
```

# Diagnosis: 9_longterm_memory_single_agent

## Root Cause Analysis

**Phase with Issue**: Code Phase

**What went wrong**:  
The explore phase successfully found relevant files about longterm memory and toolkits, including the `HumanToolkit` and `MemoryToolkit`. The code phase, however, chose to use `MemoryToolkit` instead of the required `HumanToolkit` for human interaction tools. This caused the generated agent to lack the human interaction tools explicitly required by the task. Additionally, the example queries test memory management commands rather than triggering human interaction tools. The generated code also had a runtime error related to improper initialization of `LongtermAgentMemory` (missing `vector_db_block` or incorrect setup), but the main failure is the incorrect toolkit choice and example query.

## Suggested CAMEL.md Improvements

### New Rule to Add

- When a task requires "human interaction tools," explicitly prefer and use `HumanToolkit` over `MemoryToolkit`.  
- Ensure example queries trigger the human interaction tools (e.g., prompt for human input), not just memory management commands.

### Example Pattern to Add

```python
from camel.agents.chat_agent import ChatAgent
from camel.memories import LongtermAgentMemory, ScoreBasedContextCreator
from camel.toolkits.human_toolkit import HumanToolkit
from camel.models import ModelFactory
from camel.types import ModelType

def main():
    model_backend = ModelFactory.create(model_type=ModelType.DEFAULT)
    context_creator = ScoreBasedContextCreator(
        model_backend.token_counter,
        model_backend.token_limit,
    )
    longterm_memory = LongtermAgentMemory(context_creator=context_creator)
    human_toolkit = HumanToolkit()
    tools = human_toolkit.get_tools()
    agent = ChatAgent(
        system_message="You are a helpful assistant. Use tools to interact when needed.",
        model=model_backend,
        memory=longterm_memory,
        tools=tools,
        message_window_size=5,
    )
    input_query = "What can you do for me?"
    response = agent.step(input_query)
    print(f"Agent Response: {response.msgs[-1].content}")

if __name__ == "__main__":
    main()
```

### Search Technique to Add

- When searching for human interaction tools, explicitly search for `HumanToolkit` usage and examples, e.g., `grep_search` for `HumanToolkit` or `human_toolkit` in example scripts or toolkits directory.
- Also search for example queries that trigger human interaction, e.g., `"What can you do for me?"` or similar prompts.

---

These improvements will help the code agent correctly identify and use the human interaction toolkit and write example queries that test human interaction, fulfilling the task requirements.

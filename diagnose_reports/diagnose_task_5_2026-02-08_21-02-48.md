## Suggested CAMEL.md Improvements

### New Rule to Add

- When creating an agent with MCP tools, always instantiate `MCPToolkit` via `MCPToolkit.create(config_dict, timeout)` and obtain tools via `get_tools()`. Then pass these tools to a `ChatAgent` instance. Do not pass raw config dicts directly to `MCPAgent` unless explicitly required.

- Validate MCP server config types against allowed values (`'sse'`, `'websocket'`, `'stdio'`, `'streamable_http'`). Avoid using unsupported types like `'custom'`.

- For DeepWiki MCP server usage, set an explicit timeout of 60 seconds to avoid connection timeouts.

### Example Pattern to Add

```python
import asyncio
from camel.models import ModelFactory
from camel.types import ModelType
from camel.agents import ChatAgent
from camel.toolkits.mcp_toolkit import MCPToolkit

DEEPWIKI_CONFIG = {
    "mcpServers": {
        "deepwiki": {
            "url": "https://mcp.deepwiki.com/mcp",
            "timeout": 60.0
        }
    }
}

async def main():
    mcp_toolkit = await MCPToolkit.create(config_dict=DEEPWIKI_CONFIG, timeout=60.0)
    deepwiki_tools = mcp_toolkit.get_tools()
    model = ModelFactory.create(model_type=ModelType.GPT_4O)
    agent = ChatAgent(model=model, tools=deepwiki_tools)
    query = "Use DeepWiki's tools to retrieve the architecture of the camel-ai/oasis GitHub repository."
    response = await agent.astep(query)
    print(response.msgs[0].content)
    await mcp_toolkit.disconnect()

if __name__ == "__main__":
    asyncio.run(main())
```

# Diagnosis: create an agent with MCP tools using DeepWiki server

## Root Cause Analysis

**Phase with Issue**: Code Phase

**What went wrong**:  
The explore phase successfully found relevant files including `camel/toolkits/mcp_toolkit.py` and `camel/agents/mcp_agent.py`, indicating that the exploration was sufficient to discover how MCP tools and agents are used. However, the code generation phase failed to correctly implement the usage of MCP tools as required by the task. Instead of using `MCPToolkit.create()` to instantiate the toolkit and then retrieving tools via `get_tools()` to pass to a `ChatAgent`, the generated code directly passed a configuration dictionary to `MCPAgent` as `local_config`. This led to two main issues:

1. The agent type was incorrect: the ground truth uses `ChatAgent` with MCP tools, but the generated code used `MCPAgent` with a config dict.
2. The MCP server configuration was invalid: the generated code used `"type": "custom"` which is not a valid server type (valid types are `'sse'`, `'websocket'`, `'stdio'`, `'streamable_http'`), causing a validation error and connection failure.

These mistakes caused the agent initialization to fail and the script to crash at runtime.

## Suggested CAMEL.md Improvements

### New Rule to Add

- When creating an agent with MCP tools, always instantiate the MCPToolkit via `MCPToolkit.create(config_dict=..., timeout=...)` and retrieve tools via `get_tools()`. Pass these tools to a `ChatAgent` rather than using `MCPAgent` with a raw config dict.
- Validate MCP server configuration types against allowed values (`'sse'`, `'websocket'`, `'stdio'`, `'streamable_http'`). Do not use `"custom"` as a type.
- Prefer explicit timeout configuration (e.g., 60 seconds) for MCPToolkit when connecting to potentially slow servers like DeepWiki.

### Example Pattern to Add

```python
import asyncio
from camel.models import ModelFactory
from camel.types import ModelType
from camel.agents import ChatAgent
from camel.toolkits.mcp_toolkit import MCPToolkit

DEEPWIKI_CONFIG = {
    "mcpServers": {
        "deepwiki": {
            "url": "https://mcp.deepwiki.com/mcp",
            "timeout": 60.0
        }
    }
}

async def main():
    mcp_toolkit = await MCPToolkit.create(config_dict=DEEPWIKI_CONFIG, timeout=60.0)
    deepwiki_tools = mcp_toolkit.get_tools()

    model = ModelFactory.create(model_type=ModelType.GPT_4O)
    agent = ChatAgent(model=model, tools=deepwiki_tools)

    query = "Use DeepWiki's tools to retrieve the architecture of the camel-ai/oasis GitHub repository."
    response = await agent.astep(query)
    print("=== DeepWiki MCP Agent Response ===")
    for msg in response.msgs:
        print(msg.content)

    await mcp_toolkit.disconnect()

if __name__ == "__main__":
    asyncio.run(main())
```
